# RetroIMG 0.2.1

This update fixes extremely slow Teletext hardware-constrained conversion when
using large RGB-grid palettes, such as Amiga, Mega Drive or SNES.

The fitter now searches the six pixels' possible two-colour groupings instead
of constructing millions of palette pairs. It preserves the exact colour-error
objective, palette tie order and dithering behaviour. In local testing, the
packaged Teletext/Amiga conversion completed in about 0.7 seconds including
startup and saving the full preview.

The release workflow also preserves application ZIPs during assembly, so each
download requires only one extraction.

## Downloads

| File | Use |
| --- | --- |
| `retroimg-gui-0.2.1-windows-x64.zip` | Windows desktop application |
| `retroimg-gui-0.2.1-linux-x64.zip` | Linux desktop application |
| `retroimg-0.2.1-windows-x64.zip` | Windows command-line application and interactive guide |
| `SHA256SUMS.txt` | SHA-256 checksums for the three application ZIPs |

Extract your application ZIP once and keep the complete folder together,
including `_internal`. Python and application dependencies are included.

- **Windows desktop:** run `retroimg-gui.exe` inside the `retroimg-gui` folder.
- **Linux desktop:** run `./retroimg-gui` inside the `retroimg-gui` folder.
  If extraction drops the executable permission, run `chmod +x retroimg-gui`.
- **Windows command line:** open the `retroimg` folder and double-click
  `Start guided.cmd`, or use `retroimg.exe` from PowerShell.

The downloads target x64. Windows builds target Windows 10/11. Linux builds are
made on Ubuntu 22.04 and require a compatible graphical desktop and system
libraries; minimal Ubuntu installations may need `libegl1` and `libgl1`.
These are portable folders without an installer, code signing or automatic updates.

All conversion and display features from
[0.2.0](https://github.com/SolariUK/RetroIMG/releases/tag/v0.2.0) remain available.
Include your operating system and the commit in `BUILD.json` when reporting issues.
