# RetroIMG 0.4.0

This release adds optional source-aspect matching for Teletext, retaining the
complete image while preserving the selected palette and mosaic colour rules.

## Teletext source-aspect matching

Choose **Teletext → Output geometry → Match source aspect** to keep the whole
input image without cropping, padding or distorted image proportions.
Hardware constrained still limits each complete 2×3 mosaic cell to two colours.

- A 16:9 image uses 128×72 logical pixels / 64×24 cells; enlargement 5 produces
  640×360. Portrait and other aspect ratios are calculated automatically.
- The GUI shows the calculated canvas and output size. Native and manual custom
  dimensions remain available, and existing presets keep their previous output.
- Pixel shape may adjust by up to 2%; canvas sizes are limited to twice the native
  pixel count and 512 pixels per edge. Extreme unsupported ratios give an error.
- Display effects use the calculated canvas and remain available as before.
- CLI: `--aspect-mode source` (Teletext only). The interactive guide and shared
  presets also support it. Saved matching recipes adapt to each new input.
- Custom canvases retain the visual colour/cell rules; they are not standard
  Teletext broadcast pages. Integer export dimensions can cause slight rounding.

Extract once and keep the complete application folder, including `_internal`.

These are portable folders without an installer or code signing.
