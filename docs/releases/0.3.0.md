# RetroIMG 0.3.0

This release adds source sharpening to the desktop application, command line,
interactive guide and shared presets.

## Sharpening

The **Source** tab now includes **Sharpen**, with an amount from **0 to 4**.
It defaults to **0/off**; try **1** for moderate edge enhancement.

Sharpening runs at the selected logical resolution, after resizing and the
source colour controls, before palette fitting, hardware constraints and
dithering. The converted image retains the selected palette and cell/tile
rules. Display effects still follow conversion as before.

- Source reset turns sharpening off; Display reset preserves it.
- Saved presets retain sharpening when enabled. Existing presets that omit
  sharpening preserve their previous output.
- On the command line, use `--sharpen 1`; `--sharpen 0` disables a value inherited
  from a preset.
- The interactive guide includes it under **Adjust source image**.
- Original-colour pixelation remains a separate workflow without source controls.

## Downloads

| File | Use |
| --- | --- |
| `retroimg-gui-0.3.0-windows-x64.zip` | Windows desktop application |
| `retroimg-gui-0.3.0-linux-x64.zip` | Linux desktop application |
| `retroimg-0.3.0-windows-x64.zip` | Windows command-line application and interactive guide |
| `SHA256SUMS.txt` | SHA-256 checksums for the three application ZIPs |

Extract the application ZIP once and keep its complete folder together,
including `_internal`. Python and application dependencies are included.

- **Windows desktop:** run `retroimg-gui.exe` inside the `retroimg-gui` folder.
- **Linux desktop:** run `./retroimg-gui` inside the `retroimg-gui` folder.
  If extraction drops the executable permission, run `chmod +x retroimg-gui`.
- **Windows command line:** open the `retroimg` folder and double-click
  `Start guided.cmd`, or use `retroimg.exe` from PowerShell.

The downloads target x64. Windows builds target Windows 10/11. Linux builds are
made on Ubuntu 22.04 and require a compatible graphical desktop and system
libraries; minimal Ubuntu installations may need `libegl1` and `libgl1`.
These are portable folders without an installer, code signing or automatic updates.

All features and the Teletext performance improvement from
[0.2.1](https://github.com/SolariUK/RetroIMG/releases/tag/v0.2.1) remain available.
Include your operating system and the commit in `BUILD.json` when reporting issues.
