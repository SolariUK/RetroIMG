# RetroIMG 0.2.0 — desktop preview

Convert photographs and other images into the palettes, resolutions and colour
constraints of fourteen classic computer and console families, or pixelate an
image while preserving its original colours.

This preview introduces the Windows and Linux desktop application alongside the
command-line and guided tools.

## Downloads

| File | Use |
| --- | --- |
| `retroimg-gui-0.2.0-windows-x64.zip` | Windows desktop application |
| `retroimg-gui-0.2.0-linux-x64.zip` | Linux desktop application |
| `retroimg-0.2.0-windows-x64.zip` | Windows command-line application and interactive guide |
| `SHA256SUMS.txt` | SHA-256 checksums for the three application ZIPs |

Download the ZIP for your system and extract it **once**. Keep the complete
application folder together, including `_internal`. Python and application
dependencies are bundled; no separate Python installation is needed.

- **Windows desktop:** open the `retroimg-gui` folder and run `retroimg-gui.exe`.
- **Linux desktop:** open the `retroimg-gui` folder and run `./retroimg-gui`.
  If your extraction tool drops the executable permission, run
  `chmod +x retroimg-gui` first.
- **Windows command line:** open the `retroimg` folder and double-click
  `Start guided.cmd`, or run `retroimg.exe` from PowerShell.

GitHub's automatically included **Source code** archives are for developers.
Use one of the application ZIPs above to run RetroIMG without installing Python.

## Included features

- Teletext, ZX Spectrum, Commodore 64, Amstrad CPC, BBC Micro, Amiga,
  Atari 2600, Mega Drive, SNES, NES, Master System, Game Boy, CGA and EGA profiles.
- Palette-only and machine-specific hardware-constrained conversions, including
  C64 hires cells and multicolour, console tile palettes and Amiga EHB/HAM6.
- No dithering, Floyd–Steinberg or Bayer dithering; source brightness, contrast,
  saturation, hue and individual RGB gains.
- Combined display effects: RF colour bleed, chromatic aberration, Game Boy LCD,
  scanlines, CRT aperture grille, bloom and separate display brightness.
- Original/result previews with independent mouse-wheel zoom and drag-to-pan,
  automatic output enlargement, Source/Display resets and full-size PNG/JPEG export.
- Shared JSON presets, a guided command-line workflow and original-colour pixelation.

## Platform notes

The downloads target **x64**. The Windows application targets Windows 10/11.
The Linux desktop build is made on Ubuntu 22.04 and requires a graphical desktop
and compatible system libraries. It is not a universal build for every Linux
distribution. On minimal Ubuntu installations, Qt may need the EGL/OpenGL runtime
packages: `sudo apt install libegl1 libgl1`.

These are portable folders, without an installer, automatic updates or code
signing. Automated Windows/Linux conversion, package and GUI checks pass; this
preview is intended to gather further hands-on desktop feedback. Include your
operating system and the commit recorded in `BUILD.json` when reporting issues.

Conversions and display effects export images; native retro hardware file export
is not included. Display effects operate in full RGB after palette conversion.
